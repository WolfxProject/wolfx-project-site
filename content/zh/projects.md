::page-intro{eyebrow="Wolfx Project" title="公共服务与项目"}
在这里可以查询地震和气象数据、参与地震观测，也可以使用测站可视化和短链接工具。
::

::project-grid{heading-tag="h2"}
:::project-card{title="Wolfx Open API" eyebrow="API" href="/zh/docs/open-api" image="/images/cards/API.webp" action="API 文档"}
提供地震预警、地震信息、天气、IP 归属地和时间等接口。部分数据源支持 WebSocket 订阅。
:::
:::project-card{title="Wolfx Real-time Earthquake Monitoring" eyebrow="地震监测" href="https://bs.wolfx.jp/about.html" image="/images/cards/WREM.webp" action="打开服务"}
汇集实时地震观测信息。
:::
:::project-card{title="Wolfx SeisJS" eyebrow="公众观测" href="https://seis.wolfx.jp/" image="/images/cards/seisJS.webp" action="参与观测"}
使用设备的加速度计参与地震观测。开发者可参阅[测站 API 文档](/zh/docs/seisjs-api)。
:::
:::project-card{title="Seismic Stations Viewer" eyebrow="数据可视化" href="https://ssv.wolfx.jp" image="/images/cards/SSV.webp" action="打开可视化工具"}
查看 SeisJS 测站的观测数据。
:::
:::project-card{title="ACG.kr" eyebrow="短链接" href="https://acg.kr" image="/images/cards/ACGKR.webp" action="立即使用"}
基于 YOURLS 的公益网址缩短服务。
:::
:::project-card{title="GitHub" eyebrow="开源项目" href="https://github.com/WolfxProject" icon="i-lucide-github" action="查看仓库"}
Wolfx Project 的公开源代码与开发活动。
:::
