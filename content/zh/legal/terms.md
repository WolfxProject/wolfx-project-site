本条款适用于 Wolfx Project（以下简称“本项目”）的网站、API、WebSocket、SeisJS、网络诊断等服务。使用本服务即表示同意本条款。有关信息处理，请参阅[隐私政策](/zh/legal/privacy)。

## 一、服务使用

本服务可用于商业及非商业用途。连接方式及技术限制请查阅各服务的文档。

## 二、JMA 紧急地震预警 JSON API 的二次分发

**将 Wolfx Project 提供的 JMA 紧急地震预警 JSON API（`jma_eew`）数据作为可供第三方在自身服务等场景中独立使用的数据源进行二次分发，须事先取得运营者的明确授权。** 此项限制仅针对该 API 的数据，不因通过 HTTP、WebSocket（包括 `all_eew` 等聚合频道）或其他路径获取而改变。改变格式后仍将同一数据作为独立数据源提供的，也适用此项限制。

向最终用户展示、通知信息，以及为此进行的后台处理、通信和缓存，本身不构成上述二次分发，无须取得个别授权。

已有的有效个别授权在其对象和条件范围内继续有效，不会仅因本次修订而被撤销或扩大。

## 三、非官方性质与安全提示

Wolfx Project 是独立的非官方项目，不隶属于或代表政府、气象或地震相关机构。提及数据来源也不意味着官方合作或认可。

地震信息可能延迟、出错或遗漏。本服务不能替代官方警报或避难信息。请核对官方机构的最新信息，不要将本服务作为涉及生命安全决策的唯一信息来源。

## 四、服务保护

禁止以下行为：

- 攻击系统、未经授权访问，或以过量请求、连接妨碍服务运行。
- 绕过速率限制、访问限制或其他安全措施。
- 利用本服务从事违法行为，冒充 Wolfx Project 或官方机构，或将篡改的信息伪装为真实原始信息。

为保障稳定运行，本项目可以限制请求速率及连接数，并对滥用或违反本条款的访问予以限制或暂停。紧急情况下可能无法提前通知。

## 五、权利与用户提交的信息

第三方数据及内容仍受其权利人的权利和适用使用条件约束。本条款及本项目给予的授权不会改变这些权利和条件，也不能替代必要的第三方许可。软件、文字、图像、标识等如另有许可证，适用相应许可证。

通过 SeisJS 等服务提交信息时，请确保有权合法提交。用户保留其享有的权利，本项目仅在提供、维护、保护和改进服务所必要的范围内处理这些信息。

## 六、服务变更与责任

本项目不保证信息的准确性、完整性、即时性、服务持续可用或适合特定用途。服务可能因维护、上游数据来源或运营情况变化等原因而变更、暂停或终止。重要变更或终止将尽可能提前告知；紧急情况下，在能够告知时通知。

因本项目一般过失（不包括重大过失）导致的、与使用或无法使用本服务有关的间接或特殊损失，本项目在法律允许的范围内不承担责任。此限制不适用于本项目故意、重大过失产生的责任或其他依法不得限制的责任。
