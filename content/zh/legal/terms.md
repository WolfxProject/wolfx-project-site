## Wolfx Project 服务条款 (TOS)

## 一、定义及条款接受

在本条款中，除非上下文另有说明：

- **用户**：指所有使用本项目提供的服务的个人或组织。
- **服务**：指本项目的网站、公开API、WebSocket、地震及地震预警相关信息、SeisJS、网络测试及其他相关工具。
- **隐私政策**：指本项目另行发布的信息处理相关文件。
- **专项说明**：适用于特定服务、API或数据来源的文档、使用条件、技术限制及其他说明。

用户使用本服务即表示同意本条款；不同意本条款的，不应使用本服务。

## 二、服务范围及专项说明

Wolfx Project面向全球用户提供公益性质的网络服务。不同服务可能适用不同的内容、连接方式、使用限制、数据格式和使用条件。用户应查看并遵守适用的专项说明。

专项说明与本条款不一致时，专项说明在相关服务范围内优先适用；但专项说明不得限制本条款中的安全警示或依法不得排除的权利。有关用户信息的处理，请参见 [隐私政策](/zh/legal/privacy)。

专项说明的优先适用不减轻第六条关于免费提供功能、来源标注及独立数据再提供的义务。独立数据再提供的例外须依照该条取得运营者个别明确许可，不得仅凭普通技术说明或第三方使用条件推定本项目已许可独立数据再提供。第七条关于第三方权利及适用条件的规定仍然适用。

## 三、独立的非官方服务

Wolfx Project是独立运营的非官方项目，不隶属于或代表任何政府机构、气象机构、地震监测机构、地震预警机构或其他官方组织。除非另有明确说明，提及第三方名称或数据来源不表示存在合作、认可、担保或官方授权。

## 四、地震信息及紧急情况下的使用

本服务是补充性的信息获取方式，不能替代政府或官方机构发布的地震信息、紧急地震预警、避难信息或其他紧急信息。用户应尽可能核对官方来源，不得将本服务作为生命安全、医疗、交通、避难、设备或工程控制及其他紧急决策的唯一信息来源。

## 五、数据来源、准确性及可用性

本服务的信息可能来自多个公开或合法可用的数据来源。由于通信、上游数据源、分析过程或系统原因，信息可能发生延迟、中断、遗漏、错误、重复、格式变化或不同来源之间的差异。

第三方通过自身服务器处理或转发数据时，可能产生额外延迟及故障风险。这类利用适用第六条关于正常信息利用与独立数据再提供的区分，以及第七条的适用条件。

本项目将在合理范围内维护和改进本服务，但不保证信息始终完整、准确、即时、持续可用或适合任何特定目的。

## 六、合理使用及禁止行为

用户可以依照本条款和专项说明免费使用本服务。专项说明允许的合理缓存、正常自动化访问及公益开发活动不因此被禁止。

### 商业使用及相关功能免费

个人、非营利组织、企业及其他商业组织均可免费使用 Wolfx Project API。具有广告、会员收费、订阅或其他盈利业务的网站及 App，也不因商业运营本身而被禁止使用。但使用方仍须遵守本条款、专项说明及数据来源的适用条件；允许商业使用不等于许可数据转售或本条所定义的独立数据再提供。

基于 Wolfx Project 数据向最终用户提供的对应功能，必须向所有用户完整、及时、免费开放，不得因付费状态设置差别限制。禁止以直接或间接方式将该功能付费化，包括：

- 直接收取功能使用费，要求购买付费会员、订阅或其他付费权益，或仅向付费用户开放；
- 根据是否付费或付费等级，限制数据内容、功能完整性、使用次数、地震事件、警报类别或所提供的震度信息；
- 故意延迟向免费用户提供信息，同时向付费用户实时提供，或以其他方式按付费状态设置差别限制。

即使未给某项功能单独标价，如果整个 App 或该功能的访问入口存在付费门槛，导致普通用户无法免费使用该功能，也不满足本要求。与 Wolfx Project 数据无关的功能（包括独立的高级会员功能）、产品或服务无须因此免费，广告盈利本身也不被禁止。

### 数据来源标注

使用 Wolfx Project 数据向第三方最终用户提供信息时，须以最终用户能够合理查阅的清晰方式，说明“Wolfx Project”为数据提供来源。在服务内容易找到的固定说明页面（如关于页面）统一标注，即可满足这一一般标注要求。已提供上述来源说明的，无须在每个页面、信息卡片、地图标记、弹窗或每条推送通知中单独标注 Wolfx Project，也不要求推送通知专门链接至来源页面。

不得故意隐瞒 Wolfx Project 的数据提供角色，或将其数据冒充为使用方自行发布的原始信息或官方信息。应区分原始信息发布机构、数据提供来源 Wolfx Project，以及使用方自身负责展示、通知等处理的角色。不得冒充任何官方机构，将 Wolfx Project 描述为官方地震预警机构，将 Wolfx Project 或使用方自身的服务伪装为官方机构的服务，或暗示未经明确确认的官方合作、认证、批准、授权或保证关系。上游数据来源如有更严格的来源标注条件，仍须遵守。第三条、第四条的非官方性质及安全警示仍然适用。

### 正常信息利用与独立数据再提供

本条款所称“独立数据再提供”，是指将通过本服务获得的数据，作为可供第三方脱离使用方面向最终用户的信息服务而独立获取，并用于或集成到第三方自身其他产品、App、系统或业务的数据源、数据供应服务或具有实质相同功能的服务向外提供。未经 Wolfx Project 运营者事先明确许可，不得实施此类独立数据再提供，也不得向第三方授予为此目的再利用或继续转授权的权限。

是否构成独立数据再提供，应根据提供行为的实质功能及用途判断，不能仅凭数据格式、接口名称、通信方式、是否经服务器中转、身份认证及访问限制或是否收费来决定。只要实质上仍具有独立数据源的作用，就不能因格式转换、字段改名、简单加工、访问限制或嵌入自身 App、网站而免除事先取得许可的要求。
