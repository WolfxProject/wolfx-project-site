Wolfx Project 是一个独立公益项目，以地震、地震预警（EEW）和观测数据为核心，面向开发者与公众免费提供实用的开放服务。
::

## 公共服务

::project-grid
:::project-card{title="Wolfx Open API" eyebrow="DATA API" href="/zh/docs/open-api" image="/images/API.png" action="查看规范"}
以 JSON 提供地震、地震预警与实用数据的开放 API，支持 HTTP GET 与 WebSocket。
:::
:::project-card{title="Real-time Earthquake Monitoring" eyebrow="MONITORING" href="https://bs.wolfx.jp/about.html" image="/images/WREM.png" action="打开 WREM"}
聚合实时地震观测信息，并提供公开模块的监测服务。
:::
:::project-card{title="Wolfx SeisJS" eyebrow="CITIZEN SENSING" href="https://wolfx.jp/seisjs" image="/images/seisJS.png" action="加入 SeisJS"}
利用移动设备加速度计进行地震观测，并通过联网提供公开观测 API。
:::
:::project-card{title="Seismic Stations Viewer" eyebrow="SEISMIC VIEWER" href="https://ssv.wolfx.jp" image="/images/SSV.png" action="使用 SSV"}
用于查看 SeisJS 观测信息的公开可视化工具。
:::
:::project-card{title="ACG.kr" eyebrow="UTILITY" href="https://acg.kr" image="/images/ACGKR.png" action="创建短链接"}
基于 YOURLS 的公益网址缩短服务。
:::
:::project-card{title="Service Status" eyebrow="OPERATIONS" href="https://status.wolfx.jp" icon="i-lucide-circle-gauge" action="查看运行状态"}
查看 Wolfx Project 公共服务的运行状态与故障信息。
:::
::
