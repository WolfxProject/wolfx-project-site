::project-grid{heading-tag="h2"}
:::project-card{title="Wolfx Open API" eyebrow="API" href="/en/docs/open-api" image="/images/cards/API.webp" action="API documentation"}
Access earthquake reports and early warnings, weather data, IP information, and server time. Selected feeds also support WebSocket subscriptions.
:::
:::project-card{title="Wolfx Real-time Earthquake Monitoring" eyebrow="MONITORING" href="https://bs.wolfx.jp/about.html" image="/images/cards/WREM.webp" action="Open WREM"}
Follow earthquake observations from multiple sources in real time.
:::
:::project-card{title="Wolfx SeisJS" eyebrow="OBSERVATION" href="https://seis.wolfx.jp/" image="/images/cards/seisJS.webp" action="Join SeisJS"}
Use a device accelerometer to contribute observations. The [station API](/en/docs/seisjs-api) provides access to the data.
:::
:::project-card{title="Seismic Stations Viewer" eyebrow="VIEWER" href="https://ssv.wolfx.jp" image="/images/cards/SSV.webp" action="Open viewer"}
A public viewer for SeisJS observation data.
:::
:::project-card{title="ACG.kr" eyebrow="URL SHORTENER" href="https://acg.kr" image="/images/cards/ACGKR.webp" action="Shorten a URL"}
A public-interest URL shortening service based on YOURLS.
:::
