Wolfx Project is an independent public-interest initiative that provides practical open services for developers and the public, centered on earthquake, earthquake early warning (EEW), and observation data.
::

## Public services

::project-grid
:::project-card{title="Wolfx Open API" eyebrow="DATA API" href="/en/docs/open-api" image="/images/API.png" action="Read the specification"}
An open JSON API for earthquake, EEW, and utility data, available over HTTP GET and WebSocket.
:::
:::project-card{title="Real-time Earthquake Monitoring" eyebrow="MONITORING" href="https://bs.wolfx.jp/about.html" image="/images/WREM.png" action="Open WREM"}
A monitoring service that aggregates real-time earthquake observations and provides public modules.
:::
:::project-card{title="Wolfx SeisJS" eyebrow="CITIZEN SENSING" href="https://wolfx.jp/seisjs" image="/images/seisJS.png" action="Join SeisJS"}
An earthquake-observation project using mobile-device accelerometers, with networked observations available through an open API.
:::
:::project-card{title="Seismic Stations Viewer" eyebrow="SEISMIC VIEWER" href="https://ssv.wolfx.jp" image="/images/SSV.png" action="Use SSV"}
A public viewer for SeisJS observation data.
:::
:::project-card{title="ACG.kr" eyebrow="UTILITY" href="https://acg.kr" image="/images/ACGKR.png" action="Shorten a URL"}
A public-interest URL shortening service based on YOURLS.
:::
:::project-card{title="Service Status" eyebrow="OPERATIONS" href="https://status.wolfx.jp" icon="i-lucide-circle-gauge" action="View service status"}
Operational status and incident information for Wolfx Project public services.
:::
::
