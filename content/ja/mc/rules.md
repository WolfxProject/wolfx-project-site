## 1. 総則

Wolfx Survival は、**自由度の高いバニラサバイバルを中心とする**サーバーです。プレイヤーの創造性、遊び方、通常のコミュニケーションを尊重し、**明確なルール違反がない限り、運営は介入しません**。

このルールは、すべてのプレイヤーの**通常のゲーム体験、サーバーの安定運用、公平性**を守るためのものです。運営チームが対応するのは、**ルールに明確に違反し、他のプレイヤーまたはサーバーへ悪影響を与える行為**に限られます。

## 2. 基本ルールと処分

### 1. 他のサーバーの宣伝禁止

公開チャット、個人チャット、看板、本など、いかなる方法でも他のサーバーを宣伝したり、他のサーバーへ誘導したりする行為を禁止します。

::content-notice{type="danger" title="処分"}
アカウントを永久BAN
::

### 2. 悪質な連投または大量の無意味な投稿の禁止

同一または類似した内容の繰り返し、チャットや死亡メッセージの悪質な連投など、公開チャットを明らかに妨害する行為を禁止します。

::content-notice{type="danger" title="処分"}
7日間のチャット禁止
::

### 3. 悪質または無意味な土地保護の禁止

合理的な用途がないにもかかわらず、他のプレイヤーの土地の周囲を妨害、遮断、挑発する目的で保護する行為を禁止します。

::content-notice{type="danger" title="処分"}
違反した土地保護を削除
::

### 4. 公式PVPエリアで公平性を損なうチートの使用禁止

公式PVPエリアでは、ゲームの公平性に影響するチート、ハック、その他の不正行為を固く禁止します。

::content-notice{type="danger" title="処分"}
初回：公式PVPエリアへの立ち入りを7日間禁止
2回目：公式PVPエリアへの立ち入りを永久禁止
::

### 5. 許可のない地図絵の複製・盗用禁止

地図絵の権利は、元の地図絵が存在する土地の所有者に帰属します。許可なく複製、盗用、模倣する行為はすべて違反とみなします。

::content-notice{type="danger" title="処分"}
盗用した地図絵と違反によって得たものをすべて回収
::

### 6. 他のプレイヤーの通常プレイまたはサーバーの安定運用を妨げる行為の禁止

意図的にサーバーへ異常を発生させる行為、プレイヤーが正常に接続またはプレイできない状態を引き起こす行為、その他サーバーの運用へ深刻な影響を与える行為を禁止します。

::content-notice{type="danger" title="処分"}
影響の程度に応じた期間のBAN
::

## 3. ルールの適用

ルールの適用は、**プレイヤーからの通報を主な根拠**とします。通報の際は、スクリーンショットや動画など、**明確で完全かつ確認可能な証拠**をできる限り提示してください。運営チームが証拠と実際の状況に基づいて対応します。
