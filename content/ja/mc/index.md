無料で遊べる Minecraft のサバイバルサーバーです。バニラの仕組みを生かし、同じワールドで遊び続けられます。
::

## サーバーの特徴

::mc-feature-grid
:::mc-feature{title="ワールドの引き継ぎ"}
ワールドはリセットしません。建てた家やこれまでの冒険の跡が残ります。
:::
:::mc-feature{title="バニラの仕組み"}
レッドストーン回路や農場づくり、探索はできるだけバニラのまま楽しめます。
:::
:::mc-feature{title="バージョン更新"}
安定性を確かめながら、新しい正式版に対応します。
:::
:::mc-feature{title="運営の方針"}
明らかなルール違反で他のプレイヤーやサーバーに影響が出たときに、運営が対応します。
:::
::
