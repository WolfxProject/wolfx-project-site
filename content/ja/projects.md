::page-intro{eyebrow="WOLFX ECOSYSTEM" title="公開サービスとプロジェクト"}
防災データ、観測、可視化、日常的なネットワークツールを、誰でもアクセスできる形で提供しています。
::

::project-grid
:::project-card{title="Wolfx Open API" eyebrow="API" href="/docs/open-api" image="/images/API.png" action="API 文書"}
地震・EEW、気象、IP 情報、時刻などの公開 API。WebSocket のストリーミングにも対応します。
:::
:::project-card{title="Wolfx Real-time Earthquake Monitoring" eyebrow="MONITORING" href="https://bs.wolfx.jp/about.html" image="/images/WREM.png" action="サービスを開く"}
リアルタイム地震情報の監視・集約サービスです。
:::
:::project-card{title="Wolfx SeisJS" eyebrow="OBSERVATION" href="https://wolfx.jp/seisjs" image="/images/seisJS.png" action="観測に参加"}
端末の加速度計を使った分散型の地震観測プロジェクトです。[API 仕様](/docs/seisjs-api) も公開しています。
:::
:::project-card{title="Seismic Stations Viewer" eyebrow="VIEWER" href="https://ssv.wolfx.jp" image="/images/SSV.png" action="ビューアーを開く"}
SeisJS 観測データを確認する公開ビューアーです。
:::
:::project-card{title="ACG.kr" eyebrow="URL SHORTENER" href="https://acg.kr" image="/images/ACGKR.png" action="利用する"}
YOURLS を基盤とした公益 URL 短縮サービスです。
:::
:::project-card{title="Wolfx Survival" eyebrow="MINECRAFT" href="https://mc.wolfx.jp" icon="i-lucide-box" action="WolfxMC を開く"}
2019 年から公開されている Minecraft サバイバルサーバー。復旧した中国語・英語ページを公開しています。
:::
:::project-card{title="GitHub" eyebrow="OPEN SOURCE" href="https://github.com/WolfxProject" icon="i-lucide-github" action="リポジトリを見る"}
Wolfx Project の公開ソースコードと開発活動です。
:::
