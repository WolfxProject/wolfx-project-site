::page-intro{eyebrow="Wolfx Project" title="公開サービスとプロジェクト"}
地震情報を取得する API、観測に参加するためのツール、観測データを見るためのサービスを公開しています。
::

::project-grid{heading-tag="h2"}
:::project-card{title="Wolfx Open API" eyebrow="API" href="/docs/open-api" image="/images/cards/API.webp" action="API ドキュメント"}
地震・EEW、気象、IP 情報、時刻などの公開 API。WebSocket のストリーミングにも対応します。
:::
:::project-card{title="Wolfx Real-time Earthquake Monitoring" eyebrow="地震観測" href="https://bs.wolfx.jp/about.html" image="/images/cards/WREM.webp" action="サービスを開く"}
リアルタイム地震情報の監視・集約サービスです。
:::
:::project-card{title="Wolfx SeisJS" eyebrow="市民観測" href="https://seis.wolfx.jp/" image="/images/cards/seisJS.webp" action="観測に参加"}
端末の加速度計を使った分散型の地震観測プロジェクトです。[API 仕様](/docs/seisjs-api) も公開しています。
:::
:::project-card{title="Seismic Stations Viewer" eyebrow="可視化" href="https://ssv.wolfx.jp" image="/images/cards/SSV.webp" action="ビューアーを開く"}
SeisJS 観測データを確認する公開ビューアーです。
:::
:::project-card{title="ACG.kr" eyebrow="短縮 URL" href="https://acg.kr" image="/images/cards/ACGKR.webp" action="利用する"}
YOURLS を基盤とした公益 URL 短縮サービスです。
:::
:::project-card{title="GitHub" eyebrow="オープンソース" href="https://github.com/WolfxProject" icon="i-lucide-github" action="リポジトリを見る"}
Wolfx Project のソースコードと開発の履歴を確認できます。
:::
