本規約は、Wolfx Project（以下「当プロジェクト」）のウェブサイト、API、WebSocket、SeisJS、ネットワーク診断などのサービスに適用されます。利用者は、本サービスを利用することにより本規約に同意します。情報の取扱いは[プライバシーポリシー](/legal/privacy)をご覧ください。

## 一、サービスの利用

本サービスは、商用・非商用を問わず利用できます。接続方法や技術上の制限は、各サービスのドキュメントをご確認ください。

## 二、JMA 緊急地震速報 JSON API の再配信

Wolfx Project が提供する **JMA 緊急地震速報 JSON API（`jma_eew`）のデータを、第三者が自己のサービス等で独立して利用できるデータ源として再配信するには、運営者の事前の明示的な許諾が必要です。** 対象はこの API のデータに限り、HTTP、WebSocket（`all_eew` などの集約チャンネルを含む）など、取得経路を問わず適用されます。形式を変えても、同じデータを独立したデータ源として提供する場合は同様です。

最終利用者への情報の表示・通知や、そのためのバックエンドでの処理・通信・キャッシュは、それ自体ではこの再配信に当たらず、個別の許諾を要しません。

既存の有効な個別許諾は、その対象と条件の範囲内で引き続き有効です。本改訂だけで撤回又は拡張されることはありません。

## 三、非公式サービスと安全上の注意

Wolfx Project は独立した非公式プロジェクトであり、政府機関や気象・地震関連機関に所属せず、これらを代表しません。データ源への言及も、公式な提携や承認を意味しません。

地震情報には遅延、誤り、欠落が生じることがあります。本サービスは公式の警報や避難情報に代わるものではありません。公的機関の最新情報を確認し、人命や安全に関わる判断の唯一の情報源として使用しないでください。

## 四、サービスの保護

次の行為は禁止します。

- システムへの攻撃、不正アクセス、又は過剰なリクエストや接続によるサービスの妨害。
- レート制限、アクセス制限その他のセキュリティ対策の回避。
- 本サービスを利用した違法行為、Wolfx Project や公的機関へのなりすまし、又は改ざんした情報を真正な原情報と偽る行為。

当プロジェクトは、安定した運用のためにレートや接続数を制限し、不正利用や本規約への違反がある場合は該当するアクセスを制限・停止できます。緊急の場合は事前に通知できないことがあります。

## 五、権利と利用者が送信する情報

第三者のデータやコンテンツには、その権利者の権利および適用される利用条件があります。本規約や当プロジェクトの許諾は、それらを変更したり、必要な第三者の許諾に代わったりするものではありません。ソフトウェア、文章、画像、ロゴなどに別途ライセンスがある場合は、そのライセンスが適用されます。

SeisJS などを通じて情報を送信する場合は、適法に送信できる情報を提供してください。利用者の権利は利用者に留保され、当プロジェクトはサービスの提供・維持・安全確保・改善に必要な範囲でその情報を処理します。

## 六、サービスの変更と責任

当プロジェクトは、情報の正確性、完全性、即時性、継続的な提供又は特定の目的への適合性を保証しません。保守、上流データ源や運営状況の変化などにより、サービスを変更・停止・終了することがあります。重要な変更や終了は、可能な限り事前に、緊急時は可能になった時点でお知らせします。

当プロジェクトの通常の過失（重大な過失を除く）による場合、法令が認める範囲で、本サービスの利用又は利用不能から生じた間接損害や特別損害について責任を負いません。この制限は、当プロジェクトの故意・重大な過失による責任や、その他法令上制限できない責任には適用されません。

## 七、規約の適用・変更と連絡先

本規約は日本法に従い、日本語版を正文とします。簡体字中国語版と英語版は翻訳です。これらの定めは、利用者の常居所地の消費者保護など、法令上排除できない権利を制限しません。

本規約は、別途効力発生日を定める場合を除き、公開日から適用されます。変更時は、変更後の規約と効力発生日を掲載し、重要な変更は合理的な方法でお知らせします。改訂日の記載だけで過去の利用に遡って適用することはありません。
