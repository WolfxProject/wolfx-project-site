## 概要

SeisJS の各観測点から 1 秒ごとに送られるデータを WebSocket で受信できます。

震度は気象庁震度階級、烈度は中国の震度階級（中国地震烈度表、GB/T 17742-2020）を基準に算出します。

サーバーは接続直後とその後 1 分ごとに `heartbeat` を送ります。クライアントから `ping` を返すこともできます（任意、推奨）。

**利用上の制限**　この API が提供するのは SeisJS の観測点データのみです。適法な研究・開発の目的に限り利用できます。その他の目的での利用は禁止されています。

## 観測点一覧

[観測点一覧（JSON）](https://api.wolfx.jp/seis_list.json)

観測点一覧は 10 分ごとに更新されます。観測点の状態を取得して、アプリケーションで観測点を遠隔管理する際に利用できます。

## WebSocket 接続アドレス

全観測点のデータを一つの接続で受信できます。

```text
wss://seisjs.wolfx.jp/all_seis
```

## 観測データのフィールド

| フィールド | 説明 |
| --- | --- |
| `type` | 観測点の UUID（文字列型） |
| `region` | 観測点の所在地（文字列型） |
| `latitude` | 観測点の緯度（数値型） |
| `longitude` | 観測点の経度（数値型） |
| `version` | 観測点で動作する SeisJS のバージョン（数値型） |
| `PGA` | 成分を合成した地動の最大加速度（cm/s²）（数値型） |
| `PGV` | 成分を合成した地動の最大速度（cm/s）（数値型） |
| `PGD` | 成分を合成した地動の最大変位（cm）（数値型） |
| `PGA_EW` | 東西成分の最大加速度（cm/s²）（数値型） |
| `PGV_EW` | 東西成分の最大速度（cm/s）（数値型） |
| `PGD_EW` | 東西成分の最大変位（cm）（数値型） |
| `PGA_NS` | 南北成分の最大加速度（cm/s²）（数値型） |
| `PGV_NS` | 南北成分の最大速度（cm/s）（数値型） |
| `PGD_NS` | 南北成分の最大変位（cm）（数値型） |
| `PGA_UD` | 上下成分の最大加速度（cm/s²）（数値型） |
| `PGV_UD` | 上下成分の最大速度（cm/s）（数値型） |
| `PGD_UD` | 上下成分の最大変位（cm）（数値型） |
| `Max_PGA` | 過去 2 分間の最大合成 PGA（cm/s²）（数値型） |
| `Max_PGV` | 過去 2 分間の最大合成 PGV（cm/s）（数値型） |
| `Max_PGD` | 過去 2 分間の最大合成 PGD（cm）（数値型） |
| `Max_PGA_EW` | 東西成分の過去 2 分間の最大 PGA（cm/s²）（数値型） |
| `Max_PGV_EW` | 東西成分の過去 2 分間の最大 PGV（cm/s）（数値型） |
| `Max_PGD_EW` | 東西成分の過去 2 分間の最大 PGD（cm）（数値型） |
| `Max_PGA_NS` | 南北成分の過去 2 分間の最大 PGA（cm/s²）（数値型） |
| `Max_PGV_NS` | 南北成分の過去 2 分間の最大 PGV（cm/s）（数値型） |
| `Max_PGD_NS` | 南北成分の過去 2 分間の最大 PGD（cm）（数値型） |
| `Max_PGA_UD` | 上下成分の過去 2 分間の最大 PGA（cm/s²）（数値型） |
| `Max_PGV_UD` | 上下成分の過去 2 分間の最大 PGV（cm/s）（数値型） |
| `Max_PGD_UD` | 上下成分の過去 2 分間の最大 PGD（cm）（数値型） |
| `Shindo` | 気象庁震度階級による合成震度（文字列型） |
| `Max_Shindo` | 過去 2 分間の最大震度（気象庁震度階級）（文字列型） |
| `CalcShindo` | 合成した計測震度（数値型） |
| `Max_CalcShindo` | 過去 2 分間の最大計測震度（数値型） |
| `Intensity` | 中国地震烈度表（CSIS）による合成烈度（数値型） |
| `Max_Intensity` | 過去 2 分間の最大烈度（CSIS）（数値型） |
| `LPGM` | 長周期地震動階級（数値型） |
| `Max_LPGM` | 過去 2 分間の最大長周期地震動階級（数値型） |
| `Sva30` | 水平動の絶対速度応答スペクトルの最大値。固有周期 1.6〜7.8 秒、減衰 5% の範囲で、直近 30 秒間の最大値を取ります（cm/s、数値型） |
| `Max_Sva30` | 直近 2 分間に記録した `Sva30` の最大値（cm/s、数値型） |
| `error_code` | 観測点側のエラーコード（数値型の配列） |
| `reverse` | 予約フィールド（サーバー内部検証用）（文字列型） |
| `is_desktop` | デスクトップ端末かどうか（真偽型） |
| `High_Precision` | 高精度観測点かどうか（真偽型） |
| `update_at` | データの更新時刻（文字列型） |
| `create_at` | JSON 生成時刻（文字列型） |

## WebSocket 手動クエリコマンド

```text
ping
```

## WebSocket JSON データ仕様

### 共通フィールド

| フィールド | 説明 |
| --- | --- |
| `type` | メッセージの種類または観測点の UUID（文字列型） |

### ハートビート（`heartbeat`）

| フィールド | 説明 |
| --- | --- |
| `type` | `heartbeat`（文字列型） |
| `ver` | サーバーバージョン（数値型） |
| `id` | 接続ごとの ID（文字列型） |
| `timestamp` | 送信時刻のタイムスタンプ（ミリ秒）（文字列型） |

### ping への応答（`pong`）

| フィールド | 説明 |
| --- | --- |
| `type` | `pong`（文字列型） |
| `timestamp` | 送信時刻のタイムスタンプ（ミリ秒）（文字列型） |
