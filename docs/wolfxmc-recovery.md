# WolfxMC recovery record

The June 11, 2026 archived WolfxMC page recorded a historical world/map storage size of `2.8 TiB`. That value remains here as recovery evidence, but it is intentionally no longer published as current visitor-facing server information.

The archive also showed that the historical page used mcapi.us for Minecraft availability and player information. The current site does not restore or execute the archived `minecraft.min.js` integration. It uses the documented JSON status endpoint, `https://mcapi.us/server/status?ip=Wolfx.jp`, directly from the visitor's browser and validates the response before displaying current availability or an online-player count.
